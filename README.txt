SAI VENKAT PORTFOLIO — CARLOS-INSPIRED EDITION

This is a responsive, static portfolio built from the content and images in the supplied previous portfolio export. The visual direction is inspired by the supplied Carlos portfolio reference video: dark slate background, warm yellow accent, oversized typography, centered portrait, right-side intro, editorial spacing, and restrained reveal animations.

RUN LOCALLY
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open index.html in a browser, or use the VS Code Live Server extension and choose “Open with Live Server”.

FILES
- index.html: page content and sections
- style.css: responsive layout, visual styling and animations
- script.js: loading intro, scroll reveal, mobile navigation, active nav state and contact email action
- assets/: supplied images from the previous portfolio

NOTES
- Google Fonts are loaded from the internet; system sans-serif fallbacks are included.
- The contact form uses a mailto link and opens the visitor's email application; it does not send messages to a server.
- Social profile links are generic placeholders because specific profile URLs were not included in the content export. Update them in index.html.
- A few referenced assets were missing in the old site. This build uses the available local assets instead.
- The design is a close reference-inspired recreation, not a pixel-perfect copy of the original designer's source files.
